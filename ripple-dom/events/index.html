Events

Handlers go in the element's list like everything else. on.click, on.keyDown, on.focus and the rest hand you the raw DOM event:

Value-extracting shortcuts

Some handlers hand you the value instead of the event. on.input and on.change pass the field's text; on.checkedChange passes the checkbox state:

on.input fires on every keystroke; on.change when the field is left. Both also exist as raw Event overloads when you need the event itself.

When the handler only writes a Var that the same input displays, use a binding instead - it is one line for both directions.
