Query parameters

Query parameters are matched by key, so they can appear in any order in the URL. Each combinator states how many times its key may appear; a URL that breaks the rule is a parse error, not a silent default.

CombinatorKey appearsProduces
Parser.Query.Required.string "q"exactly oncestring
Parser.Query.Optional.string "q"zero or one timestring option
Parser.Query.strings "tag"any number of timesstring list
Parser.Query.flag "draft"bare key, present or absentbool

int variants exist beside every string one, and custom variants beside Required and Optional.

Required, optional, flag

The last two fail. A missing required key and a duplicated single-value key are both errors, and the message names the key.
