Selectors

Signal.selector turns a signal into a function that tells whether a key is the current value of the signal. When the signal changes, only the readers of the previous key and of the next key run again.

Usage

The second write does not reach the readers. Row 2 does not run again, because its key is neither the previous value nor the next value.

In a list

Use a selector when each row of a list compares the same signal to its own key:

A click runs the bindings of two rows: the row that loses the selection and the row that gets it. With selected.Value = item.Value.Id, a click runs the binding of every row.

Keys

Reads outside an effect

Outside an effect or a binding, for example in an event handler, isSelected key returns the current result.

Lifetime

Create the selector in the scope that uses it, for example in the component function. The selector stops when that scope is disposed.
