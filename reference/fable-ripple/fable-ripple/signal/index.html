Signal

[<Struct>]
type Signal<'T> =
    | Signal of node: Var<'T>
AssemblyFable.Ripple
Attributes[<Struct>] [<Erase>]

Read-only view of a signal. A zero-cost [<Struct; Erase>] wrapper: at runtime it IS the underlying Var node (no allocation, no indirection - Fable erases the wrapper), but it exposes only a getter, so writing a computed fails to compile. Combinators accept a source (Var) or a Signal alike via SRTP.
