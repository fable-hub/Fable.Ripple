Var

[<Class>]
type Var<'T> =
    create<'T> (initial: 'T) : Var<'T>
    createWith<'T> (equals: 'T -> 'T -> bool) (initial: 'T) : Var<'T>
    member Signal: Signal<'T>
    member Value: 'T with get, set
    member Peek () : 'T
    member Set (v: 'T) : unit
AssemblyFable.Ripple
InheritsReactiveNode
ImplementsSignal<'T>

The reactive node and the writable handle. A source (Var.create) is a Var<'T> you read and write; a computed is the same node type built with a recompute function but handed back read-only as a Signal<'T>. ONE runtime class backs both, so every read stays monomorphic (no dispatch, no hidden-class polymorphism). Reading .Value inside a computation registers a dependency.

Functions and values

create<'T> (initial: 'T) : Var<'T>

Create a writable source (structural equality).

createWith<'T> (equals: 'T -> 'T -> bool) (initial: 'T) : Var<'T>

Create a writable source with a custom cutoff equality (a write is a no-op when the new value is equals the old).

Properties

member Signal: Signal<'T>

This source as a read-only Signal. Rarely needed: every Signal parameter accepts a Var directly. Use it to store a source in the same collection as derived signals.

member Value: 'T with get, set

The current value. Reading tracks a dependency and pulls the signal up to date; setting notifies observers when the value differs. A computed is only handed out as a read-only Signal<'T>; writing one through a downcast throws.

Methods

member Peek () : 'T

Read the current value without registering a dependency.

member Set (v: 'T) : unit

Set the value (same as the Value setter).
