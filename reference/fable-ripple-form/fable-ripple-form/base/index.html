andThen<'A, 'B> (child: 'A -> Form<'B>) (parent: Form<'A>) : Form<'B>

Builds the rest of a form from the output of its first part.

The child form is built when the parent's output changes and disposed when it changes again, in its own Signal.root. Values live in the Vars the child reads, so a child built again finds them. While the parent fails, the result is the parent's errors.

Parameter
childBuilds the child form from the parent's output
parentThe form filled first

Returns. A form with the parent's items followed by the current child's, whose output is the child's

andThen over a value that carries a form, such as a wizard.

Parameter

append<'A, 'B> (newForm: Form<'A>) (current: Form<('A -> 'B)>) : Form<'B>

Appends a form to another one and feeds its output to the function the other one yields.

The errors of both forms are collected: the result is Error with the first error and the others as soon as either form fails.

Parameter
newFormThe form to append
currentThe form to append to, whose output is a function

Returns. A form with the items of both, whose output is the function applied to the new form's output

field<'Input, 'Attributes, 'Output when 'Attributes :> IAttributes> (isEmpty: 'Input -> bool) (render: FieldRenderConfig<'Input,'Attributes> -> DomItem) (config: FieldConfig<'Attributes,'Input,'Output>) : Form<'Output>

A form with one field.

The field's Result is computed from its Var: RequiredFieldIsEmpty while isEmpty holds, then the parser's result, then the config's external error. The render function is called by the view with a FieldRenderConfig built from the config and the RenderContext of the subtree.

Every field constructor of a renderer is this function with a render function:

Parameter
isEmptyWhether a value counts as empty, for the required check and IsEmpty
renderDraws the field
configHow the field behaves

Returns. A form with one item and one handle

validateAsync<'Output> (debounceMs: int) (check: 'Output -> Promise<Result<unit,string>>) (form: Form<'Output>) : Form<'Output>

Runs an asynchronous check on the output of a form once it parses, after a debounce.

Validating is true while the check runs. A rejection is shown on every field as an External error. A result that arrives after the output changed again is dropped. A view waits for a pending check before submitting.

Parameter
debounceMsMilliseconds after the last change before the check starts
checkThe check, given the parsed output
formThe form to check

Returns. The form, failing while the last check rejected its output
