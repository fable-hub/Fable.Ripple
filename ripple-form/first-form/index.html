Your first form

A sign-up form: an email, a password, its repeat, and a newsletter checkbox.

Submitting gives a User record, and its fields are not strings: an Email can only be made through Email.tryParse, so a User holds a valid address by construction.

One Var per field

Every field stores what the user typed in a Var. You create them, so you can read or write them from anywhere: set a default, prefill from a server, watch them, etc.

A field

A field is built in three steps. The attributes say how it looks; Field.create ties it to its Var and gives it a parser; the constructor picks the field kind.

The parser turns the text into your type, or into a message for the user, every time the value changes. Email.tryParse is one already.

Putting the fields together

Form.succeed takes the function that builds the result. Each Form.append gives it the next field's value, in order. The repeat field's value is not needed, so its argument is _.

Showing it

Form.View.asHtml renders the form with a submit button. OnSubmit receives the User once every field parses; until then, submitting shows the errors instead.

Fill the password, then type something else in the repeat: its error appears as soon as you leave the field. Fix the password instead: the repeat's error goes away, because its parser re-ran.

The view config has five parts:

  • OnSubmit: what to do with the result.
  • State: a Var you write. Loading disables the fields and the button; Success and Error show a message under the form.
  • ErrorVisibility: which errors are showing. One per form, from View.errorVisibility ().
  • Action: SubmitOnly "label" for one button, or Custom to draw your own; see Saving and loading.
  • Validation: when a field starts showing its error; see Validation.

Reading the result without submitting

The form is a value with signals: form.Result is the current Ok user or the errors, form.IsEmpty tells whether everything is blank. A "Save" button can be disabled while form.Result.Value is an Error, and a preview can read the record as it is typed.
